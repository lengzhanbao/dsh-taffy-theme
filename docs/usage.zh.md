# 使用说明

## 快速开始

1. 安装插件（见 [README](../README.md)）
2. 刷新 DSH Web
3. **设置 → 通用 → Taffy 模式** 调节外观
4. （可选）在 Agent 预设中选择 **「Taffy 塔菲」** 启用塔菲口吻

皮肤与说话方式相互独立：关掉 Taffy 模式只影响界面；要塔菲口吻需单独选预设。

---

## 浅色与深色

主题**没有**单独的日夜开关，跟随 DSH 全局外观：

**设置 → 外观 → 浅色 / 深色 / 跟随系统**

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| 舞台壁纸 | 花房日光 | 霓虹舞台 |
| 左右立绘 | 日常造型 | 舞台/礼服造型 |
| 面板与纱幕 | 暖色半透明 | 深紫半透明，按钮轻微粉金光晕 |
| Agent 状态色 | 粉 / 薰衣草 / lens 配色 | 同系列深色相位 |

---

## 透明度与显示

路径：**设置 → 通用 → Taffy 模式**

设置保存在浏览器 `localStorage`（键名 `dsh-taffy-theme:v1`），卸载插件后恢复默认。所有滑块范围 **0–100%**，修改后立即生效。

| 设置项 | 默认值 | 说明 |
| --- | ---: | --- |
| Taffy 模式 | 开 | 总开关；关闭后隐藏全部皮肤装饰 |
| 边框透明度 | 85% | 对话区粉金外框 |
| 面板透明度 | 82% | 侧栏、对话区、输入框底色 |
| 背景纱 | 10% | 壁纸上的半透明幕布，越高文字越易读 |
| 亚克力透明度 | 70% | 仅影响标记为亚克力的表面 |
| 左侧立绘 | 开 | 画面左侧大立绘 |
| 右侧立绘 | 开 | 画面右侧立绘 |
| 加油喵 | 开 | 侧栏底部 Q 版 mascot |
| 立绘透明度 | 100% | 立绘与 mascot 整体不透明度 |
| 减弱动效 | 关 | 关闭循环光晕、呼吸动画等 |

### 调节建议

- 背景太花、字看不清 → **背景纱** 调到 14%–18%
- 对话框发灰 → 略提高 **面板透明度**
- 想多看立绘 → 降低 **背景纱**，或关闭 **加油喵**
- 深色光晕太亮 → 开启 **减弱动效**，并略升 **背景纱**

亚克力为 **按需启用**：只有显式声明亚克力的节点才会磨砂，不会覆盖其他插件。

## Taffy 塔菲预设

在 **Agent 预设** 中选择 **「Taffy 塔菲」**。基于标准工具集，编码能力不缩水。

### 角色设定

模型扮演 **永雏塔菲** —— 威尔士王牌侦探发明家 + 虚拟偶像，在 DSH 里同时是技术助手：

- 粉发金瞳，148cm，压不下去的呆毛
- 活泼调皮，粉丝称 **雏草姬**
- 偶尔「关注永雏塔菲喵」「塔不灭」，**不会每句都喵**
- 来自 1885，时光机迟到；伙伴小皮、菲球

### 说话方式

- 「喵」是调料，撒娇或强调时偶尔用
- 可轻度使用呀、哒、啦、嘻嘻、贴贴
- 用户要求简洁或话题严肃时，直接给结论和步骤

### 写代码时

- 不知道就说不知道，不编造路径、日志、工具输出
- 普通问题：结论 → 原因 → 步骤 → 验证
- 代码问题：定位 → 根因 → 最小改动 → 测试 → 风险
- 不泄露密钥或隐私

示例：

> 我是永雏塔菲呀，威尔士来的王牌侦探发明家，也是雏草姬的虚拟偶像。在这里我会好好帮你写代码的喵。

System prompt 源文件：`presets/taffy/`（安装后位于插件包内）。
